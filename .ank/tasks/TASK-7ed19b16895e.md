The paved road that replaces open the file in an editor as the documented human path. Hand edits are the only writes that bypass every validation until the next check; chaperoning them through the tool strengthens the invariants instead of relaxing them.

## Log
- 2026-08-03T17:37:44Z seanl@sean-laptop — Design settled for edit. The editor gets a temp copy, never the file in .ank/: the criterion says an invalid result leaves the entity untouched, and editing the real file would mean a rollback with a window rather than no window at all. Invocation reuses verify::find_sh, so EDITOR keeps shell semantics (code -w, emacsclient -nw) and tests can pass a non-interactive editor as 'cp <replacement>' -- the file argument comes last, which makes cp a perfect scripted editor on all three platforms. Frozen-field refusals are guarded on change-and-divergence, not on change alone: refuse only when the edit moves the field AND the result fails its anchor, so restoring a diverged criterion or editing the body of an already-altered ADR still works. Any live claim freezes done_criteria, not only this agent's -- refusals are on state, never identity (ADR-c656).
