Implements ADR-9307e5d214a7. Read it first: the distinction the work turns on is
between coordinating, which needs an arbiter, and reading a corpus, which needs a
parser, and the current gate collapses the two.

`cli.rs` calls `startup()` for every verb but `help`, `config` and `--version`,
and `startup()` calls `git::ensure_usable()` — a version check plus
`rev-parse --show-toplevel`, both hard code 9. Removing the call is the easy half.

The hard half is `repo.rs`. Repository resolution currently *is* the git
toplevel, so with the gate gone there is no root to resolve. Walk up for `.ank/`
instead. `human.rs` already enumerates the corpus with a filesystem walk rather
than `git ls-files`, so this removes a second way of answering one question
rather than inventing one.

Three call sites already degrade when the default branch is unknown — `status.rs`,
`context.rs`, `human.rs`. Extend the same treatment to "no repository at all": the
coordination plane reads as empty, one warning, never a failure. Do not add a
second degradation path; reuse those.

`check` is where the care goes. It grows two halves, one of which can be absent,
and the line announcing the skip is not optional — a check that silently examines
less than it did is how a corpus passes a gate that stopped looking. Get that line
into the human output and into `--json`.

Watch the ordering trap: `git::ensure_usable` also enforces the 2.34 floor. A
coordinating verb must still get that check, so `require_git()` has to do both
things, not just the toplevel.

The byte-identical clause in the criterion is the regression guard. This task is
supposed to change what happens outside a repository and nothing whatsoever
inside one, and the only way to know is to diff the output.
