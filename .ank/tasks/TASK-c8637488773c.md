A structural hole in the plan rather than a discovered subtask: the scopes of the
five remaining CLI tasks are verb modules, and none of them contains main.rs. The
dispatch they all presuppose therefore belonged to no task's scope. This task
also creates the empty verb modules that dispatch routes to, which leaves each
verb task with its single file, without amending any scope.

Argument parsing is written by hand (§12). The justification is character-level
control over two surfaces read by agents: the self-correcting errors, which a
generic parser would replace with its own messages, and `ank help`, which §9 says
carries the flag details — generated help is verbose, and its cost is paid on
every call that triggers it. The edge cases listed in the criterion are where
hand-written parsing goes wrong, and they look like business bugs once in
production.

git missing, too old or outside a repository exits with 9 per ADR-92b9cda9f6a9,
to be ratified. The plumbing goes through the git binary, plumbing only.

`init` lands here rather than in a separate task: it is the command of the
starting point, it shares nothing with the loop verbs, and its perimeter is
narrow (§9). The `.gitattributes` it writes is two lines, and it is what stops
the CRLF bug from being reborn for every user — fixing it only in this repository
would have left it intact everywhere else.
