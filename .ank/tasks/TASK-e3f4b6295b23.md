Section 7 of the spec states the nominal case: one working tree per agent -
clones or git worktree - each on its own branch, with several agents sharing one
tree called a degraded mode rather than a design mode. docs/getting-started.md
repeats it under "One identity per session" and adds the part that bites:
two terminals with no $ANK_AGENT are the same agent, so they see and silently
renew each other's claims (identity.rs:33-58 falls back to <user>@<hostname>).

skill/SKILL.md says none of it. Its only mention of a branch is "finished on
another branch" in the list of reasons claim refuses. It never tells an agent to
work on its own branch, never mentions worktrees, never mentions ANK_AGENT. An
agent that has loaded the skill and nothing else - which is the whole point of a
skill - knows the loop and does not know the execution model the loop assumes.

That matters more than a documentation gap normally would, because the coordination
the skill DOES teach is only correct under that model. "It refuses when the task
is held" is true between agents with distinct identities; two sessions sharing a
fallback identity get a silent renewal instead of a refusal (claim.rs:628-631),
which is the opposite outcome from the one the skill implies.

The remedy is not free, and that is why this task records the tension rather than
prescribing the fix. ADR-c656dfc33a9 freezes the CONTENT of skill/SKILL.md
precisely because it is loaded permanently: growing what it teaches costs a
superseding ADR and a human signature. Three candidate exits:

1. Supersede the ADR and add two or three lines to the skill. Highest value per
   byte, highest procedural cost, and the ADR exists to make that cost real.
2. Leave the skill alone and make the tool say it at the moment it matters -
   claim already warns when one identity holds several tasks (claim.rs:906-914);
   the same place could name the model once.
3. Decide the omission is correct - harnesses set up worktrees, not agents - and
   record that reasoning here so the question stops being reopened.

The criterion is written to accept any of the three: what it forbids is the
current state, where nothing in the corpus says which one was chosen.
