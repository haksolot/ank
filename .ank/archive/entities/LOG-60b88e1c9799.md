 The reading half is all one-letter commands, and the asymmetry is what makes 'no action without an explicit keystroke' a property of the grammar instead of a habit of the renderer -- there is no 'd', so a finger that slips onto it has typed nothing. done and release with nothing after them pass through bare so the CLI answers for the flag it wants; that is how a person meets error[5] and its way out rather than a sentence this crate wrote. log with no message is the one line the reader refuses itself, because ank log <id> alone reads the log, and quietly doing the other thing is the surprise. A note is now measured rather than assumed to be one line: a document has a field per line and a refusal has two.
