 Counting outside dependents per component in the break alone was NOT enough: the transitive property test still failed on a spread graph (N3 frees N1 once drawn while N2, on N3's cycle, still reaches N1 through it). The free rule was per node too. Fix: a component opens only once every component with an edge into it is drawn whole; inside it a node is free when its same-component dependents are drawn; the break picks the earliest node of an open component. Acyclic graphs: one node per component, so the walk is unchanged (259 lib tests green, no literal moved).
