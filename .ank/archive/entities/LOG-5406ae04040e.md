The working-tree side is batched git hash-object, which is already allowed plumbing (section 12) and, unlike a byte comparison of the two texts, applies the same CRLF conversion the commit did -- read literally, a Windows checkout with core.autocrlf on would differ from the default branch in every single file and elsewhere in none. Measured on this corpus: check goes from 32.5s to 35.0s warm.
