title: Claims live in git refs, never in the files
created: 2026-07-27T09:15:00Z
status: accepted
scope:
  - crates/ank-cli/**
constraint: |
  A claim is never written into a task file. It lives in
  refs/ank/claims/<task-id>, one ref per task. Ank never commits, except
  accept, which produces the signed ratification commit.
schema: 1
version: 2
---

The two planes are orthogonal: durable state is replicated and versioned,
coordination is ephemeral and disposable. Writing a claim into the file would
produce a git diff on every task pickup — exactly the noise the separation exists
to avoid.

One ref per task rather than a global ref: two agents taking two different tasks
must never fight over the same ref update. Git's compare-and-swap then arbitrates
exactly the conflict that matters.
