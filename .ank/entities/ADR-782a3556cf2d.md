## Context

ADR-e3cb36646d77 refused a distribution plan built on five satellite
repositories, one per agent ecosystem, each carrying its own copy of the skill.
The refusal was right and this ADR keeps it entire: a copy without an anchor
drifts, nothing turns red, and one day an agent is taught the opposite of a
ratified decision.

What the wording did not anticipate is a channel whose *registry* is a git
repository. On the AUR a package **is** a repo: there is no other place a
PKGBUILD can live, and no amount of design moves it into this tree. Read
literally, the current constraint forbids Arch packaging outright — not because
anybody weighed it, but because the sentence was written against a different
shape.

## The distinction

**A registry you publish into is not a satellite you maintain**, and the test is
where the source of truth lives.

npm's registry already receives a package this repository derives at release
time, and nobody calls that a satellite. `microsoft/winget-pkgs` is the same
shape: a central index that accepts a manifest and holds no authority over it.
homebrew-core and the AUR are that shape too. In every case the artefact is
produced from a tag, by the pipeline, and its content is a function of a commit
in this repository.

What ADR-e3cb36646d77 was actually refusing is the other thing: a repository a
human keeps in step. That is where drift comes from, because nothing derives the
copy and nothing compares it. The rule survives with its teeth — it just names
the property that made those five repositories wrong, instead of the fact that
they were repositories.

## What this does not license

**A channel this repository can serve, it serves.** The measurement matters
here, because two of the three channels that look like they need a satellite do
not. `brew tap <user>/<name> <url>` takes an arbitrary URL, so `Formula/ank.rb`
in this tree is a working tap. A Scoop bucket is any git repository carrying a
`bucket/` directory, so `bucket/ank.json` in this tree is a working bucket. Only
the AUR is structurally forced, and it is forced by its own design rather than by
convenience.

So this decision buys exactly one thing: the AUR. Everything else stays where it
already was, and a future channel has to show that it *cannot* be served from
here before it earns a push target.

## Rejected

**Leaving the constraint alone and skipping Arch.** Defensible, and it makes a
packaging decision by accident: the letter of a sentence written about skills
would decide which operating systems get a native install. A rule should refuse
things somebody weighed.

**Widening it to "any repository the project controls".** That is the plan
ADR-e3cb36646d77 refused, restated. Control is not the property that matters;
derivation is. A satellite you control drifts exactly as fast as one you do not,
because what drifts is the copy nobody recomputes.

**A homebrew-ank tap alongside.** It would buy `brew install haksolot/ank/ank`
without the URL, and it is the one satellite this ADR would have made legal.
Refused on the rule above: the tap can be served from here, so it is.

## Consequences

`packaging/aur/` carries a PKGBUILD template, and a release job renders it and
pushes it to the AUR under an SSH key held in Actions secrets. Nothing about it
is edited by hand between releases; if it ever is, the drift this ADR still
forbids has arrived through the door it just opened, and `check` will not see it
— which is why the job derives the file rather than updating it.
