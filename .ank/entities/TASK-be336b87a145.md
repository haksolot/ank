The decision is ADR-4b45f344344f. Measured 2026-09-14: `refs/ank/proof/*` holds 205
refs, 3.3 MB, 20 518 attestation entries for 205 facts; TASK-b2c3d4e5f6a7
alone carries 171, one per CI run between 2026-08-13 and 2026-08-30, all
`test:<run>` on the same criteria hash by the same identity. The attest job
stopped re-attesting on 2026-08-30 by fetching what it had written; the
binary never stopped taking the entry.

**The fact** is (type, criteria hash, identity). A second attestation of
the same fact replaces the first in place, so the ref's size is the number
of distinct things said about the task and `show` lists the latest run.
`--compact` applies the rule to a ref written before it, and is what the
205 existing refs get once, pushed one by name. The `--json` surface of
`attest` gains nothing retyped (ADR-6fd69efb629c); the recipe in
`docs/getting-started.md` names `--compact` for a corpus that predates
the rule. The write path is `human::attest` (`human.rs:5789`) and the
record read at `claim.rs:876-910`.
