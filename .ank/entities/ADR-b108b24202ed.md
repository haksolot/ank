GitHub #790, item 1. `SECURITY.md` places enforcement in a harness hook that cannot be talked out of it, and today only a Claude Code session gets one: a team mixing harnesses gets the guarantee for one agent and an advisory regime for the others.

The protocol alone unblocks every other harness: its user wires `ank hooks run generic pre-tool-use` in a few lines, with no release per vendor, the argument docs/ci.md makes against a --format per CI system.

Named adapters (Codex CLI, Gemini CLI, Cursor, OpenCode) are left for later, one amendment each, because each is a byte-exact settings format that install and remove must round-trip, and that has to be measured against the real harness rather than read from its documentation.

`ank hooks status`, item 3 of the issue, adds a subcommand, which ADR-376bed7fa39a allows only through its supersession, and is carried there.
