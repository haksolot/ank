docs/format.md says index.db is disposable and deleting it is always safe, and
also that an archived file whose bytes change is a fault. Measured on
2026-09-19: archive three entries, edit one, check reports the fault; delete
index.db and the fault is gone for good. The digest the fault compares against
lives only in the cache.

ADR-467ce7e9cda1 governs the cold half. If holding the digest outside the cache
needs a decision (where it is anchored), release with the question rather than
choosing one silently.
