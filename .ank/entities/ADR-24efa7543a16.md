## Context

ADR-9a0076dd0896 froze the surface and asked that any addition arrive as its
supersession, naming the property it serves. The integration by hooks, the
pattern herdr, moshi and mise already use, needs a verb: something has to write
the harness's configuration, and something has to answer when the harness calls.

## Decision

The surface gains one verb, `ank hooks`, with its subcommands `install`,
`remove` and `run`. It serves a rule that is an entity anchored by hash and
served by scope: today the rules reach an agent only when it thinks to ask
`ank context`; a hook serves them at session start and before a tool call,
whether or not the agent asked. What `ank hooks` does is decided by its own ADR;
this one only admits it to the surface.

Everything else of ADR-9a0076dd0896 is restated unchanged.
