Ratified by ADR-d3a8dcf38817, which carries the decision and the reason the
in-place translation of frozen fields is legitimate today and will not be once
real anchors exist.

Order imposed by ADR-63b59c5c26f7: specification first, then the golden
fixtures, then the code. The specification examples and the goldens describe the
same entities, so they are translated as one step and compared against each
other — a divergence between them is a format bug, and one was found this way
(the `criteria` hash in a proof entry existed in the goldens and in the code
without appearing in the specification example).

The mechanical floor is this, run from the repository root:

    grep -rIniE '[àâäçéèêëîïôöùûü]|\b(le|la|les|des|une|est|pas|qui|dans|pour|avec|sans|donc|tache|fichier|verrou|aucun|plutot)\b' --exclude-dir=.git --exclude-dir=target .

It is a floor and not a proof. French without accents and without those words
would pass it, so it catches residue rather than establishing quality; the
criterion above is what establishes quality, and it is read by a human. Writing
it down anyway is what makes the residue impossible to leave behind by accident,
which is where a translation of this size actually fails. It earned its place
immediately: it caught `.ank/allowed_signers`, which the rename pass had missed
because the file contains no occurrence of the old name and is not an entity, so
`check_repo` never looks at it.
