The successor written by TASK-36666e36744e is `SPEC-fe8bdb84faca`, and the
moment Sean signs its ratification `SPEC-20357e21a45a` becomes `superseded` --
which is when `no_superseded_document_is_cited_in_the_workspace` starts reading
six citations of it as stale.

**This is the same shape as TASK-5f5752d724af**, which repaired the citations
the previous ratification of this document retired, and it is filed for the same
reason: `amend --reference` carries every entity that cites a predecessor, and
prose inside a source file is outside that mechanism by design
(ADR-1e6bcbf62e61).

**The repair is a reading, not a substitution.** `verbs.rs` states a rule and
cites the document that states it for every verb at once, so that citation moves
to whatever binds then. `view.rs` holds the identifier as a fixture value in a
renderer's tests, where what it stands for is a row of the right shape rather
than a document anybody follows. `skill.rs` recounts what one landing did once,
which is history, and history is what `ank show` serves -- so that citation may
go rather than move. The test allows both ways out, and which one each line
takes is what this task decides.

It is deliberately not folded into TASK-36666e36744e: repointing a citation at a
document nobody has signed yet would be the workspace naming as binding a thing
that is not.
