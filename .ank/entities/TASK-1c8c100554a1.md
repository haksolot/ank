ADR-64f32c74a0f9. TASK-161c402c27fb already reads the latest version; this half
hands a version to a route.

The npm route is recognised by where the running executable sits, not by a
guess: the npm package resolves the platform binary from its own node_modules
tree (npm/ank/bin/wrapper.js). Read it before deciding the test.

The installer route: install.sh takes --version, --dir and --no-welcome
(install.sh --help), install.ps1 takes the same as -Version, -Dir and a
no-welcome switch; read both before building the command. How the script
reaches the machine (piped from the raw URL, as the README documents) is part of
what the stubs record.

Windows cannot overwrite a running .exe but can rename it; measured on this
machine when replacing ~/.local/bin/ank.exe during parallel sessions.
