`--version`; read the six files whole and hand them to the crate as bytes. The
directory the verb writes goes under the platform's temporary directory, and
the verb prints its path, because that path is also the fallback: a machine
without node runs the printed command later, against the same directory.

skills of this tree. The skills CLI detects the agent it runs under and installs
non-interactively when one is detected; when none is, it asks its own scope
question, which is why the installers set npm_config_yes. Pass the same, and
prove the argv the stub receives rather than reading the code that builds it.
