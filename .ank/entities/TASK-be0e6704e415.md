Found while landing TASK-e0d72ec220a1, which puts the METHOD line on the page
`ank context` prints after a claim and asked for nothing on `--json`. The page is
what an agent at a shell reads; the document is what everything else reads. `ank
mcp` spawns `ank context --json` per call, so an agent reaching ank over MCP is
served the criterion and the constraints and never the method, and `ank tui`
draws from the same document. ADR-a8f9c603a0e7 binds the recommendation to the
moment execution starts, and on those surfaces it would not arrive.

A field gained is what a contract version allows without a bump (ADR-6fd69efb629c),
`criteria` already sits in the document as an optional string, and `method` is
the same shape. Whether the terminal reader should draw it is not decided here.
