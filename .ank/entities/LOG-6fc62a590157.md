(1) No raw mode, and it is not a shortcut: keystroke input is tcsetattr on Unix and SetConsoleMode on Windows, two extern blocks this workspace does not otherwise have, and CLAUDE.md holds that OS-dependent behaviour is unverified until it has run on all three -- only one of the two can be run from here. The terminal's own line discipline is the input layer, a command is a short word and Enter, and the screen is full-screen all the same: alternate buffer, repainted whole. It buys back arguments, so 'f adr', '/claim' and 'TASK-4974' are commands rather than modes. (2) The window is read from COLUMNS and LINES rather than measured, for the same reason and with the same escape hatch: an ioctl is FFI, and a suite that could not choose the window could not assert what a frame holds. (3) serde_yaml reads the CLI's --json, which is what ank-mcp already does with JSON-RPC: YAML 1.2 is a superset of JSON and the escaper on the other side emits only backslash-quote, backslash-backslash, backslash-n and backslash-u00xx, every one of which a double-quoted YAML scalar carries. No crate enters the tree. (4) The pseudo-terminal in tests/tui.rs declares posix_openpt, grantpt, unlockpt and ptsname itself. libc is in the lockfile but is not compiled for this target, and what is needed is four symbols and O_RDWR, which POSIX fixes at 2.
