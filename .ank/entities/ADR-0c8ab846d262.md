## Context

ADR-962c25797569 bought colour with a negative guarantee: what a pipe receives is
byte-for-byte what it received before. That was the right guarantee for colour,
and it was written as though it covered everything the CLI would ever draw.

It does not. `ank graph` renders a DAG as two spaces per level, so depth is
counted by hand and a diamond is invisible; `show`'s edge sections and
`context`'s wrapped constraints render relation and continuation as the same
whitespace. Making those legible means emitting characters, not escapes — and
962c's sentence forbids it in as many words. A constraint that has to be
reinterpreted to be followed is a constraint that has stopped binding.

## Decision

The guarantee is re-cut along the line that actually matters.

Colour is a property of the reader. An escape sequence means nothing to a
parser, so it is emitted only when a human is demonstrably at the other end,
and there is no flag able to force it anywhere else.

Structure is a property of the corpus. A tree is what the `blocked_by` edges
are, and drawing it one way for a human and another way for an agent would give
one corpus two renderings: the two would stop reading the same text, "what did
the agent see" would become a question with two answers, and the attention
budget of section 5 would depend on who was watching. So structure ships in the
bytes, everywhere, and its character set is declared in the specification before
any code moves — the same argument section 4 already makes for the short-form
table.

`--json` carries neither. It is the machine surface, and it is the one place
where both halves would be wrong.

Ank already writes non-ASCII to stdout — the em-dash separating a log entry's
author from its message — and Windows CI has been green on it throughout, so
box-drawing introduces no new class of risk on any platform.

## Rejected

**Terminal-only glyphs**, gated on the same detection as colour. It leaves
962c's sentence intact and costs no ratification, which is its whole appeal. It
also gives one corpus two shapes and makes truncation a function of the
terminal. The cheap option here is the one that reintroduces the second surface
ADR-e17e1bbd93ff exists to deny: one surface, read the same way by everyone.

A colour crate, and `--color=always`: refused for the reasons 962c gave, which
this decision carries forward unchanged.
