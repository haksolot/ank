Implements the CI half of ADR-376bed7fa39a, which must be accepted first.

Measured on 2026-10-26 at e04c0dad: with `api` absent, every binding from it
degrades to a warning and `ank check` in `web` exits 0. That default stays: a
laptop without the sibling is not wrong. What CI lacks is a way to say it
expects the sibling, so a decision binding two repositories is never confronted
with either tree there.

The recipe checks the sibling out (actions/checkout with a path, or a plain git
clone in the job); ank itself never clones (ADR-96fe1f9d619a). An edge whose
peer task is not yet merged stays a signal under --peers: requiring the peer
to be readable is not requiring the other repository to have merged
(ADR-09b985a5627e).
