**The reader may not link `ank-cli`**, so `crates/ank-cli/src/config.rs`'s list
of declared keys is out of reach. The keys exist in `ank-contract` today only as
a space-separated line inside a verb note -- a string to split rather than a
list to read. Promoting that line to a `pub const` in `ank-contract`, with
`ank-cli`'s own list and the note both rendered from it, is a one-file change
and it is the difference between one table and three.

**`config` is the one verb on both roads.** `ank.rs` asserts today that nothing
on `ACTS` is on `READS`, and the property it protects is real: a repaint calls
`Ank::json`, so a verb on both roads is a verb a watcher's news can reach. The
answer is a named exception of exactly one verb, and a gate that reads the
argument shape rather than the name -- one positional is a read, two is a write,
and the writing shape is refused on the reading road.
