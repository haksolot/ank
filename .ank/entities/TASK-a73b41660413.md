The half of ADR-a22cd3196529 that touches somebody else's repository, which is
why the criterion spends more of itself on what must not move than on what must.

**The negative test is the point of this task.** A background process writing
into a repository where a person is working is the failure this decision spent a
paragraph refusing, and "we only fetch `refs/ank/*`" is a sentence that stays true
right up until a refspec is written slightly wrong. Listing the things that must
be identical afterwards, and asserting them against a repository that has
something to lose, is what turns the sentence into a property.

**Two clones is the only honest fixture.** The thing being fixed is that
`status` reports what another agent holds out of a stale local copy of the refs.
That cannot be demonstrated in one clone, and a test that tried would be
measuring nothing.

**A dead network is a normal Tuesday.** The daemon is optional by construction,
so a failed fetch downgrades what it offers and never stops it, and never reaches
the exit code of anything the person is running.
