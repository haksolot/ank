 Maintained by upsert and forget inside the same transaction as the entity rows, so the two cannot disagree. Ranking is bm25 with documented positional weights, id above title above slug above criterion, and the identifier breaks ties so the order is total. User text never reaches FTS5 as syntax: every term is quoted and suffixed with a star, which is why OR, NOT and a stray quote come back as no match instead of an error. Two things found rather than assumed: there is no fts5 feature on rusqlite 0.40 because bundled already compiles SQLITE_ENABLE_FTS5 in, and the search is now prefix rather than substring.
