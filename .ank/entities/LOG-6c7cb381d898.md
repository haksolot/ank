 last-but-one line. 'gh pr view main' -> 'no pull requests found for branch "main"', exit 1; the recipe leaves the shell on main after 'git reset --hard origin/main', so a bare 'gh pr merge --merge' there exits 1. Naming the branch, 'gh pr merge ratify/<id> --merge', is the fix; the archive recipe is unaffected because 'git switch -c' puts you on the branch.
