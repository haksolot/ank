The binary is a static musl build, so the package depends on no libc and the
control file says so: this is the rare .deb that is genuinely architecture-bound
and dependency-free.

**The signing key is a new one, and that is not a preference.** Section 8's
authority model rests on the ratification key being the single hard line in the
system: `accept` produces a signed commit and `check` verifies it against
`.ank/allowed_signers`. Signing packages with that key would put the same
signature on two claims of entirely different kinds — this decision was
ratified, and this binary is the one we built — and the whole value of the line
is that it means one thing. A separate distribution key, published beside the
repository, and the ratification key never leaves its own job.

Hosting is GitHub Pages of this repository, so the index lives where every other
channel lives and no satellite appears.
