§9 puts the seven commands and the mental model in SKILL.md and sends flag
detail to `ank help`, "loaded on demand". SKILL.md says so in as many words, and
was shipped that way in v0.1.0 and installed as a skill. `ank help` does not
exist:

    $ ank help
    error[1]: unknown command 'help'

An agent that follows the file it was given lands on an error. This is the same
defect TASK-0da5af5afd5f cleared out of the README -- prose pointing at
something that is not there -- and it was introduced on the same day, by me,
which is the argument for the test rather than the habit.

**Not a growth of the agent surface** (ADR-2f8a61c04b7d). The seven verbs are
what an agent *works* with; `help` carries no work and changes nothing. It is
the mechanism that keeps the surface at seven by giving flag detail somewhere
else to live. Worth stating in the ADR's own terms when the time comes, rather
than assuming the reading is obvious.

The dispatch error above already lists every verb, so the listing exists and has
no command in front of it.
