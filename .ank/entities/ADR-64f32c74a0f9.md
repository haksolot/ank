## Context

The binary has no way to reach a newer version of itself: a person re-runs
whichever of the three routes ADR-221aa5da440a names they remember using, and
an agent has no way to know a newer release exists at all. The skills now travel
inside the binary (ADR-e1d750884b82), so a stale binary also means stale skills.

Measured 2026-09-13 before this decision: the binary links no HTTP client, no
TLS and no archive library; install.sh and install.ps1 already take `--version`,
`--dir` and `--no-welcome`, fetch the archive and its `.sha256` from the release
and verify it; `git ls-remote --tags --refs https://github.com/haksolot/ank`
lists v0.5.0, v0.6.0 and v0.7.0, and ls-remote is in the plumbing ADR-9307e5d214a7
allows.

## The decision

Delegate. The route that placed the binary knows how to replace it, and it is
already tested on three platforms. ank decides only which route that is and
which version, and hands over.

- **npm**: the running executable sits inside the `@haksolot/ank` package tree,
  and npm owns that tree; replacing the file under it would leave npm's record
  wrong.
- **installer**: any other released binary. The installer is told the directory
  the running executable is in, so the update lands where the old one was, and
  `--no-welcome`, so it asks nothing. On Windows a running executable cannot be
  overwritten but can be renamed, so the running one is moved aside before the
  installer writes.
- **built from source**: a binary under a cargo target directory was placed by
  no route, and an update would silently swap a development build for an older
  published one. Refused, naming cargo build.

A version older than the running one is installed only when `--version` names
it; without it, a running binary at or above the latest release is up to date.

Only an explicit `ank update` reaches the network. A notice printed by other
verbs would be traffic and output every agent pays for on every run, the cost
ADR-f3d1 refuses.

## Rejected

A native self-update in Rust: downloading, verifying and swapping the archive
itself. It needs HTTP, TLS and tar/zip in the one executable ADR-1ea31c2f3c5a
ships, and a second implementation of what the installers already verify, which
drifts from them.

Reinstalling the skills as part of update: it chains npx and the network behind
a verb that was asked to update a binary.
