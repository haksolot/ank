## Context

pi was served by two manifests: the private `@haksolot/ank-pi` at the
repository root, read by `pi install git:`, and the `pi` key of the published
npm package, read by `pi install npm:`. The second needed a copy of every skill
under `skills/`, assembled at release by `npm-assemble.sh` and checked by the
release smoke job, plus a PNG card generated by `assets/make-card.mjs` because
the pi gallery refuses SVG. Nothing else reads any of it: the binary embeds the
skills since ADR-e1d750884b82, and `ank skills --install` places them for every
agent the skills CLI knows.

## Decision

The maintainer drops pi as a channel. The copy, the card, the manifests and the
documentation section go together, because each exists only for pi.

## Why an amendment

ADR-e1d750884b82 stays right on everything else: the binary carries the skills
and `ank skills` installs them. Only its last sentence named pi. Amending it
keeps the rule binding and leaves its citations in place.
