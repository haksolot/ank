The safety net of the reuse cache: a way to ask whether what the local
registry would let done skip still passes, without a claim and without
writing a proof.

A flag on an existing verb, not a new verb: ADR-89c1 freezes the verb list,
and flags are how a verb evolves. On verify rather than done because done
--fresh already reruns everything inside a close, and a failing rerun there is
simply a failing done; what is missing is a claimless audit that compares a
rerun with the recorded pass. verify writes no proof (ADR-c621cb9c6739), and
that stays true under --audit: the audit's output is feedback, its runs only
feed the registry, which ADR-c621cb9c6739 already allows.

Which verifiers it reruns is defined by the registry (the ones done would
reuse right now), not by the diff, because those are exactly the ones a diff
selection skips.

Waits on TASK-06f91cff057e, which measures whether verify consults the
registry today, and on TASK-5733fc48b9b5, which reshapes the run loop this flag
runs through: both write verify.rs, so they land one after the other.
