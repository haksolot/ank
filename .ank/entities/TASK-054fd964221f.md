Every macOS channel below rests on a binary that does not exist. The matrix
carries `aarch64-apple-darwin` and nothing for Intel, so a Homebrew formula and
an install script would both resolve to a 404 on half the Mac install base —
and they would do it at install time, on somebody else's machine, which is the
worst place to discover a missing artefact.

It is first because it is a prerequisite and not because it is large: the matrix
already has the shape, and this adds a row.
