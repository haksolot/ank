A Scoop bucket is any git repository carrying a `bucket/` directory, so this
repository is its own bucket and no satellite is created — ADR-e3cb36646d77
holds unchanged.

Scoop is the lighter of the two Windows channels and the one that needs nobody's
permission: winget requires a pull request into a registry somebody else
reviews, and this requires a directory.
