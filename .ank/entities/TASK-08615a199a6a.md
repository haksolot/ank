Issue #501, the edge itself. Implements ADR-c23bef1cc93e: **do not claim this
before it is accepted.**

The rule to keep in view: an edge whose peer cannot be read is not satisfied.
The degrade-and-answer-locally rule of ADR-a1de673043b4 is for readers; applied
to a blocker it would release exactly the work the edge exists to hold. The
refusal still names the peer and the command, so it is never a dead end.

"Done" is the peer task's status as the peer's corpus holds it on disk, the read
`context` already makes through the peer. No fetch. Claims stay per repository.
