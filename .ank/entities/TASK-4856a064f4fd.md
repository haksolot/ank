Implements ADR-ebe85b3aa79d (amends ADR-7224dea611c1), which is proposed: do not claim before a human has ratified it.

ank config writes the three keys like the others (ADR-e64dfaafd578): vars.<NAME>, inherit_env as a list or false, cwd as a string. The hash covering the new keys must leave the hash of a verifier that declares none of them unchanged, or every recorded run in every corpus stops being reusable on upgrade: state in a test that the hash of a run/timeout/inputs verifier is the same before and after.
