Implements ADR-4d9fb7375dc1, which is proposed: do not claim before a human has ratified it.

Read first: where a refusal is rendered today (crates/ank-contract/src/exit.rs describes the prose form, crates/ank-cli/src/main.rs writes it) and how the MCP server turns a refusal into content[0].text and stderr (crates/ank-mcp). The tests go in a new file, crates/ank-cli/tests/refusal_json.rs, so this task shares no test file with the work running beside it; tests/mcp.rs is extended for the MCP half.
