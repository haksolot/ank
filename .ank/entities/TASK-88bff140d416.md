ADR-96174f1ac2b7 is the decision; this is the reading half of it. The corpus is
found, anchored through the flag TASK-a12553192afa added, and nothing is
created or written.

**The order of resolution is the whole of the surface**, and it has four cases:
`--repo` given, which short-circuits everything as it always did; a declaration
matching this repository's identity, which wins over the tree and says so on
standard error; no declaration, which is the walk of section 6 unchanged; and
neither, which is the refusal that already exists, naming `ank init`.

**The identity is read, never invented.** TASK-d55cef0b0ef1 derived it from the
root commit and put it in `ank status --json` as the first field gained under
the contract, which means the key a user needs is already printable with a
command that exists. A tree with no history answers the declared fallback that
task documented, and a fallback is not a key: a declaration keyed on it is
refused rather than matched, or every historyless tree on a machine would share
one corpus.

**Refusing the slug is behaviour, not commentary.** The shape of the request
this comes from was a directory named by the slugified remote URL, so the map
will be handed slugs by people who read that thread. A key that is not an
identity is refused by name, with the command that prints the right one, which
is the difference between a design that says no and a design where a wrong key
silently matches nothing and the corpus quietly is not found.

**Platform matters here more than usual.** The home directory is
`$XDG_CONFIG_HOME` or `$HOME` on two platforms and `%APPDATA%` on the third,
and CLAUDE.md is explicit that OS-dependent behaviour is not verified until it
has run on all three. The test drives the binary with the environment set, not
the function that reads it.

**What must not be built.** No directory is searched, guessed at or created. No
value is derived from a remote, and a declaration that names a path holding no
corpus is a refusal naming the path, not a fallback to the walk: falling back
would make a typo in the map indistinguishable from having no map at all.
