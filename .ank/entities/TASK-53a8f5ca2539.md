Implements ADR-894d4bfbf9bd, which lands proposed. Ank has no edge from a task
to a decision, so it is stated here: do not claim this task before that
decision is ratified on the default branch. `ank review` shows whether it is.

The cursor is `expires - ttl` on the held claim record, derived and never
stored: `ClaimRecord` is `deny_unknown_fields`, so a new field would break
every older binary reading a shared ref. What moved is read from the planes
`context` already opens (the index for entity mtimes, the coordination plane
and the watcher's mirror for claims and completions), so criterion (5) is
ADR-cc65f1388a71's invariance and not a ceiling.

`context` is declared `Renews::Never` in `crates/ank-contract/src/verbs.rs`
because its positional is a path. The renewal `--since` performs has to be
addressed to the held task and not to a positional, which is the one place
this touches the verb table.
