The decision is ADR-306fdb75e265; this task is the writing half. Cold is a superseded
document, and a log entry whose subject is a task done on the default
branch -- the predicate `check` already holds for completion refs
(`done_on`). A task is never moved. The move is a rename through the store,
so `git` sees it as one; no commit (§12), like `done`, and the result lands
by pull request like a ratification because it is a human deciding what
the hot corpus is. The recipe goes in CONTRIBUTING.md beside accept's.
