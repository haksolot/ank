constraint: |
  A verb that changes an entity's content outside a status transition writes a log entry recording the fields it changed, the version it moved from and the version it moved to, and the hash of the state it replaced. The entry anchors nothing: no authority rests on it and no verb refuses on it, which is what ADR-ff294eff4d1a requires of the log, and the hash exists so that a reader can verify a past state described to them. An entity carrying at least one such entry is accounted for, and from then on a version it cannot account for is a check signal naming both counts. An entity carrying none is silent, because the corpus is not migrated by a rule it predates. Nothing here refuses an edit: what the trace buys is that the ordinary case becomes legible, not that the dishonest case becomes impossible.

`version:` is a counter, and a counter is not a record. It says an entity was
written N times and nothing else: not when, not by whom, not what moved. The
model carries `created` and `author`, which name the act of creation and never
an edit, and ADR-3877fef1d662 makes `author` unchangeable precisely so that it
keeps meaning that.

**Git does not close it, and the hole is demonstrable rather than theoretical.**
ADR-9e56318631f3 was created and then rewritten before its first commit, so it
enters the history already at `version: 2`:

    $ git log --oneline -- .ank/entities/ADR-9e56318631f3.md
    90e1456 ratify ADR-9e56318631f3
    faf3178 plan: detached corpus, anchor and location split
    $ git show faf3178:.ank/entities/ADR-9e56318631f3.md | grep version
    version: 2

Version 1 existed nowhere a reader can reach. What was rewritten between the
two was not cosmetic: a sentence was added to the `constraint`, which is the
binding part. A human ratified version 2 having been told what it said, and the
corpus cannot show them that version 1 said something else.

**The window this is about is exactly the window that matters now.** After
ratification the anchor covers it: `check_anchor` reports an altered entity as a
*fault* and an altered ADR stops being injected into `context`. Before `new`
there is nothing to alter. Between the two, a proposal is drafted, argued and
rewritten, and until now nothing recorded that it had been. That window used to
be short and human. It is now where an agent does most of its writing.

**Why the trace and not a wall.** ADR-6b3f19e08a24 settles that immutability is
verifiable by hash and never defended by the CLI, and ADR-3877fef1d662 says the
same of identity in a sentence this decision deliberately borrows: the
convention is a signal and not a wall, and what a field buys is that the
ordinary case becomes legible, not that the dishonest case becomes impossible.
A verb that refused to edit would hold only the honest, since the file is
writable by anything, and it would trade a real property for a reassuring one.

**Why an accounting rather than an inventory.** A trail nobody counts is a
trail nobody reads. The signal is what gives the trace teeth: to hide an edit
you must now forge two things that a single write cannot both fix, the version
the entity carries and the entries it accounts for. That is the same shape as
every other guarantee here, where the freeze lives somewhere the editor of the
file cannot reach.

**Why the first entry opens the regime.** The alternative was a bootstrap
exception, a schema bump, or a creation entry per entity, and each buys less
than it costs: a schema bump drags a migration behind a question that is not
about format, a creation entry doubles a corpus whose read cost is already an
open task, and a rule with no discrimination at all fires on a thousand
entities at once, which §11 names as the volume that teaches a reader to stop
reading `check`. Letting the first trace open the regime needs none of them:
every existing entity stays silent until the CLI next edits it, and that edit
opens the account by itself.

**What is left uncovered, stated rather than left to be discovered.** An entity
edited exactly once, by hand, outside the CLI, carrying no entry, is
indistinguishable from one never edited at all. That is not a defect of this
decision but the shape of every guarantee in this corpus: the file is writable,
and what the tool offers is the anchor beside it. For a ratified entity the
anchor already answers; for a proposed one, nothing does, and this decision
narrows that to the single case above rather than closing it.
