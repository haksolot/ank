The reader ADR-8bd76e8d7c4e allows, in its read-only half. Blocked on the
Commands block carrying `tui`, because a verb that dispatches before the
specification lists it turns `skill.rs` red.

**The dependency assertion is the constraint made mechanical.** ADR-8bd76e8d7c4e
forbids linking `ank-core` and forbids touching `.ank/` and `refs/ank/*`
directly, and a rule that lives only in prose is a rule the second contributor
breaks for a good reason. A test that reads the crate's own dependency graph
turns "there is one dispatch path" from a claim into something that fails the
build.

**Driven through a pseudo-terminal, because CLAUDE.md leaves no choice.** A
criterion that talks about the binary is tested through the binary, and twice in
this repository green unit tests covered code the binary never reached. A TUI is
the extreme case of that trap: every interesting behaviour lives behind terminal
setup that a unit test does not perform.

**Refusing without a terminal is not a detail.** `ank` is run by agents far more
often than by people, and an agent that types `ank tui` by accident must get a
refusal it can read rather than a process that hangs holding a terminal it does
not have.
