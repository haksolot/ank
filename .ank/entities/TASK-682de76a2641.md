The second thing ADR-e39a44f80e0e requires. Blocked on the release carrying
`ank-mcp` at all, because an installer that unpacks it can only be measured
against an archive that has it.

**The older release is the case that decides the shape.** `install.sh` accepts
`--version`, so it will be pointed at archives published before this task
existed, and a hard failure there would break a route that works today. Hence the
criterion asks for a missing `ank-mcp` to be reported and survived rather than
fatal: the person asked for ank, and ank is what that archive can give them.

**Measured on all three, not on one.** CLAUDE.md states the rule this task is the
textbook case of: OS-dependent behaviour is not verified until it has run
everywhere, and this is a POSIX `sh` script and a PowerShell script placing files
and setting permissions. `install.yml` already runs the three; it gains an
assertion rather than a job.
