The reader shipped in TASK-49746735127f, gained the writing half in
TASK-b50b340c0bb1, an event stream in TASK-2f7777a1fdff and ratification in
TASK-d90e94afca08. What it never had is a shape somebody wants to sit in front
of. lazygit is the reference, and it was the reference before any of this was
written -- the intention simply never reached the corpus, so the planning that
produced the current screens could not see it. This decision is where it lands.

## The reason for the line discipline has expired

`crates/ank-tui/src/lib.rs` explains at length why a command is a word and Enter,
and the explanation is honest: "Raw mode is two implementations of one behaviour,
`tcsetattr` on Unix and `SetConsoleMode` on Windows, each behind an `extern`
block this workspace does not otherwise have. CLAUDE.md's rule is that
OS-dependent behaviour is not verified until it has run on all three platforms,
and only one of those two can be run from where this was written."

Both halves have stopped being true. This repository's CI runs Linux, macOS on
two architectures and Windows on every pull request, and it earns its keep --
TASK-1317adb617e8 shipped green on two platforms and red on the third, on
exactly the class of defect that rule exists to catch. And crossterm *is* the
cross-platform implementation of that behaviour, maintained and exercised far
beyond what this workspace could give it, so taking it adds no `extern` block
here at all. The constraint that produced the line discipline was a constraint
on what could be verified, and it has been lifted by the suite rather than
argued away.

## What fifty-five crates buy, and why that is the honest number

The workspace lockfile carries fifty packages. ratatui and crossterm bring
fifty-five more, so this single verb slightly more than doubles the tree. The
number is written here rather than discovered later by whoever runs `cargo
tree`.

What it buys is a panel layout with focus, borders, scrollbars and popups, and
an event model covering keys, mouse and resize. Written by hand, that is the
project this repository is not building, and `frame.rs` -- which already
implements wrapping, fitting and windowing, carefully and with tests -- is the
first eighth of it. crossterm alone would cost twenty and give the input half
without the drawing half; that was weighed and refused, because a panelled
reader is what was asked for and the layout is the part that is expensive.

The trade this project usually makes is the opposite one, and it is worth being
plain about the asymmetry. `gix` and `clap` were both refused. Neither refusal
generalises here: `gix` lost to the git binary because signing is cryptography
and the binary was already a hard dependency, and `clap` lost because generated
help and generated errors are surfaces agents read. A drawing library replaces
no surface an agent reads and reimplements nothing this project already has --
`ank tui` is the one verb no agent should be reaching for at all.

## What a confirmation is, and what it is not

Today no line of one letter can write, and that asymmetry *is* the guarantee: a
finger that slips onto `d` has typed nothing, because there is no `d`. A
keystroke reader cannot keep that property, so it must replace it rather than
lose it.

The replacement is a confirmation that shows the argv. Not a "are you sure" --
the exact command, spelled as a shell would have to spell it, which is the same
thing the screen already prints above every answer. A person confirming has read
what they are about to run; a finger that slipped is looking at a dialog it did
not mean to open, and dismisses it. And it is strictly stronger than what it
replaces in one respect that matters: today `done commit:abc` runs on Enter with
nothing shown first.

`accept` keeps everything TASK-d90e94afca08 gave it on top of this. It is typed
on the document, it carries nothing beyond the single identifier, and no
passphrase can be answered from this process.

## Mobile is a constraint on the layout, not a feature beside it

A terminal on a phone sends mouse events on a tap, wraps at forty columns or
fewer, and puts a keyboard over half the screen when one is needed. Those three
facts constrain the layout, the event handling and the affordances -- which is
why they are decided here and not after the panels exist. A reader that reflows
because somebody remembered to test it narrow is a reader that stops reflowing.

What this does not do is soften ADR-894defc26f3d, which ADR-8bd76e8d7c4e kept:
the browser reader stays outside this repository. A phone driving a terminal is
a terminal.
