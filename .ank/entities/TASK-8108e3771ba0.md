so `tui` is a line in that block before it is a line in `COMMANDS`.

means a verb that dispatches while the successor is still in the queue turns the
suite red. So the declaration lands first, as a verb that does not ship yet --
the suite already has a case for exactly that -- and the implementation follows
the human signature rather than racing it.

is signed, on the default branch, by a person. This task ends with the successor
in the queue and says so.
